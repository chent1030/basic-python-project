## 用户裁决（2026-09-27）

1. **FR-09/10/11/12 全部保留并补做**：记忆体系是产品核心——agent 必须能根据历史审核情况自主进化，使用越久越贴合实际。D-17 取消的是"记忆审核**人**角色"，不涉及"记忆能力本身"；前者是治理结构问题，后者是产品核心，必须区分。
2. **FR-03/04 收缩为框架能力保留**：保留 agent_runs 框架端点与 LangGraph 运行时，业务编排暂不做（CPS 流程确定性状态机驱动足够覆盖）。
3. **FR-06 编辑环节不做**：与 §21.1 一致。
4. **FR-08/10 不挂起**：按主计划执行，观察 Agent 优化建议 + 历史/覆盖分析报表均为 P1 必须项。

## 自我反思（编排者教训）

本节原建议"关闭 FR-09/11/12"是错误的过度引申——把"D-17 取消人工审核角色"扩大为"取消记忆能力"，混淆了**治理结构**与**产品能力**两个层面。记忆审核角色不参与不代表记忆体系关闭，反而更凸显**自动化记忆**的价值（agent 自主积累经验而无需人工把关）。

教训记录：评估某项决策的范围影响时，必须区分**该决策涉及的实体**与**依赖该实体的能力/设施**——若决策仅移除"角色/治理层"，不应连带关闭"被治理的能力层"。
