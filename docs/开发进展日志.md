### 契约澄清（写入联调结论）

- C-01 载荷 `issue_id`/`submission_id` 为 **字符串**（Python schema string_type）；`review_task_ref == task_id == 幂等键`。
- **重放语义**：同载荷重放 → 202 + `replayed:true`（返回缓存结果，**不重发回调**）；同键异载荷 → 409。Java 侧恢复路径=30s 扫描器（timeout_at=submitted+600s → TIMEOUT_OPEN），符合 PRD §28.4 迟到留痕。

- 无附件路径：IMAGE_COMPARE/MEASURE_SIMILARITY/TEXT_VALIDITY=SKIPPED（不伪造通过），overall=PARTIAL 由文本规则驱动（model_version=text-rules/d-22@1）；语义/视觉检查待线 A6/A7 接入。
